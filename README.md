# Crumbe-Camp Backend 🚀

API RESTful desarrollada en **Java** y **Spring Boot** para la gestión robusta de la lógica de negocio, autenticación de usuarios y persistencia de datos en la nube.

---

## 🛠️ Tecnologías y Stack Utilizado

* **Lenguaje:** Java 17 / 21
* **Framework:** Spring Boot 3.x (Spring Web, Spring Data JPA, Security)
* **Base de Datos:** PostgreSQL (Cloud hosting en Supabase)
* **Contenedorización:** Docker & Dockerfile
* **Despliegue y Cloud:** Render

---

## 📌 Características Principales

* **API RESTful:** Endpoints estructurados para la gestión eficiente de recursos y lógica de usuarios.
* **Persistencia Cloud:** Conexión y mapeo de datos relacionales mediante JPA/Hibernate hacia una base de datos PostgreSQL alojada en Supabase.
* **Seguridad y Roles:** Implementación de lógica de autenticación y control de permisos de usuario.
* **Contenedorización:** Configuración mediante `Dockerfile` para asegurar la portabilidad y estandarización del entorno de ejecución.
* **Despliegue Continuo:** Aplicación desplegada y activa en la nube utilizando Render.
